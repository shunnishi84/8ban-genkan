# Gemini（Argon）用 指示プロンプト — 「8番玄関」を作る

以下を丸ごと貼り付けて使う。既存の画像（`public/assets/images/` の中身）を zip でまとめて添付できるなら添付し、
「添付の画像をこのファイル名のまま使って」と一言足すと見た目が揃う。添付しない場合は、画像が無くても
Canvas の図形と色だけで遊べるように作らせる（プロンプト内で指示済み）。

```
あなたはベテランのゲーム開発者です。以下の仕様どおりに、ブラウザで動く日本語のゲーム
「8番玄関」を最後まで作ってください。途中で質問せず、仕様にない細部は「仕様の雰囲気に合う方」
を自分で決めて進めてください。完成したら、起動方法と仕様との対応表を短く報告してください。

# 1. ゲームの概要
- 「8番出口」のパロディ。飲み会帰りのサラリーマン（主人公＝プレイヤー）が自宅マンションの
  玄関前に立っている。その日、妻を怒らせる「火種」が隠れているので、玄関前や持ち物・スマホを
  調べて火種を見つけ、街（コンビニ・ゴミ捨て場・公園のベンチ）で対処してからドアを開ける。
- 火種が残ったままドアを開けると、怒った妻が待っていてゲームオーバー（1日目からやり直し）。
- 8日連続で無事に帰宅できたらクリア。火種がない「異変なし」の日もある（8番出口と同じく、
  何もないのに疑って引き返すと時間だけ失う）。
- 雰囲気: シュールで笑えるコメディ。夫婦げんかネタだが、流血・暴力・性的描写は一切しない。
  妻のセリフは「静かに怖い」「理屈で詰めてくる」方向で面白くする。

# 2. 技術仕様
- TypeScript + Vite。ランタイム依存ライブラリなし。描画は HTML5 Canvas（背景・妻の絵・演出）
  + DOM（ボタン・メッセージ窓・スマホ画面）。
- スマホ縦画面（9:16）優先。PC では中央に縦長で表示。タップだけで全操作できること。
- 構成はロジックと見た目を分ける:
  - src/core: 純粋なゲームエンジン（DOM を触らない）。状態 DayState、行動 Action を受けて
    新しい状態と結果（Outcome）を返す。乱数はシード付き。
  - src/data: シナリオ・アイテム・チャット定型文・フィナーレをすべてデータで定義
    （シナリオを1件足すだけで抽選対象になる、データ駆動の設計）。
  - src/ui: 画面遷移・描画・音。
- テスト（Vitest）: 「どのシナリオも、どの組み合わせでも時間内に解ける」ことを
  自動ソルバーで検証する。参照しているアイテム・定型文・画像が存在するかもテストする。
- 保存は localStorage に最高連続記録だけ（読み書きは try/catch で包む）。
- デバッグ用 URL: `?debug` で今日のシナリオ・未解消の火種・解答例を画面上部に表示。
  `?debug&scenario=id1,id2` で1日目のシナリオを固定。`&finale=castle` などでフィナーレを固定。
- 画像は public/assets/images/ に置き、無い画像は既存の画像か Canvas の図形で代用して
  エラーにしない。BGM・効果音も同様に、無くても動く。

# 3. 時間のルール
- 時刻は分単位で進む。開始時刻は 22:50 + (日-1)×4分 + 0〜10分のゆらぎ。
- 各行動の所要時間: 調べる 1分 / 持ち物の欄やスマホのアプリを開く 1分 / チャット送信 2分 /
  通販の注文 3分 / 注文キャンセル 2分 / コンビニで買う 2分 / 捨てる 1分 / 使う 2分 / 拾う 1分 /
  送信取消 2分 / SNS 投稿削除 2分 / シャツを脱ぐ・着る 1分。
- 移動: 玄関前 ⇄ 街 5分。街 → コンビニ 3分、ゴミ捨て場 2分、公園のベンチ 1分。
  （店などから街へ戻るのは0分。）
- 23:59 まで: 通販の特急便は翌朝着（それ以降の注文は明後日着で意味がない）。既存注文の
  キャンセルや誤爆メッセージの送信取消も 23:59 まで（0:00 に妻が既読にする）。
- 0:30 を過ぎると時計が赤くなる。
- 1:00 を過ぎてからドアを開けると、火種に関係なく「遅すぎる」で怒られてゲームオーバー。
- 2:00 を過ぎると妻は寝てしまう。チャットは既読にならず、ドアにはチェーンロックがかかって入れない。
  公園のベンチで「時間をつぶす」（1回60分）を繰り返し、朝 6:00 に帰ると「朝帰り」で怒られる。
- 日が進むと火種が重なる: 1〜5日目は1つ、6〜7日目は2つ、8日目は3つ。
  1〜5日目は 25% の確率で「異変なし」の日になる。
- 同じ周回で同じシナリオは重複させない。同じ日に組み合わせると矛盾するシナリオは
  conflictsWith で除外する。

# 4. 画面と操作
- タイトル → 「はじめる」 → その日の導入文（「『もう一軒だけ』が三軒になった。22:57、自宅の
  玄関前に着いた。」のような短文）→ 玄関前。
- 上部バー: 日数、連続帰宅数（例 1/8）、時刻、音のオンオフ。
- 玄関前で調べられる場所: ドア / 廊下 / 窓 / 表札 / 足元。初回は1分かかり、手がかりのテキスト
  （とあれば絵）が出る。ニセの異変（火種に関係ない気になる描写）も混ぜる。
- 下部ボタン: 「持ち物」「スマホ」「引き返す（街へ）」「ドアを開ける」（確認ダイアログあり）。
- 持ち物: 鞄 / ワイシャツ / 財布 / 名刺入れ の4つの欄。アイテムごとに「捨てる」「使う」
  「飲む」「着替える」などのボタン。ワイシャツの欄には「脱ぐ」ボタンもある（脱いだまま帰ると
  「なんて格好で帰ってきてるの！」で怒られる）。
- スマホのアプリ: チャット（妻とのトーク） / カレンダー / メモ / ポチッとマート（通販） /
  SNS（その日のシナリオで必要なときだけ）。
- チャット画面: 上に妻とのやりとり（手がかりのメッセージは末尾に（22:41）や（昨日）の時刻を付け、
  複数の火種が重なっても時刻順に並べる）。下に送れる定型文の一覧。
  - 「定型文を送る」の欄と、赤い「😤 感情のままに送る（※おすすめしない）」の欄の2つに分ける。
  - 送信条件を満たしていない定型文は一覧に出さない（例: 注文済みでないと「注文した」報告は出ない）。
    条件を満たした時点で現れる。
- 街: コンビニ / ゴミ捨て場 / 公園のベンチ（ここから通販も使える、アプリを開くのは0分） /
  玄関前に戻る。
- コンビニ: 商品一覧と値段。買うと鞄に入る。
- 結末の会話画面: 背景＋妻の絵＋下のメッセージ窓。タップで1行ずつ進む。名札付き（妻 / あなた /
  ナレーション / 義母 など）。
- ゲームオーバー画面: 「原因: ○○」、連続記録、最高記録、「1日目からやり直す」「タイトルへ」。
- Android の戻るボタン相当: 開いている画面を閉じる → 店から街へ → プレイ中はタイトルに戻るか確認。

# 5. 火種の解き方の仕組み
- 状態はフラグの集合。例: bought:milk（買った）、ordered:bouquet（通販で注文した）、
  chat:birthday（その定型文を送った）、discarded:garbage_bag（捨てた）、used:ring（使った）、
  canceled:golf_club（注文をキャンセルした）、unsent:wrong_send（送信取消した）、
  deleted:post_meshi（SNS投稿を消した）。
- 火種ごとに解消条件を { all: [...] } / { any: [...] } の入れ子で書く。ドアを開けた時点で
  全部の火種の条件が満たされていれば帰宅成功（各火種の successLine を妻が言う）。
- 関係ない謝罪の定型文を送ると、妻から電話で問い詰められて 8 分失う。ただし「今から帰るね」
  「ほんとにごめん…」などには、その日の状況に合わせた妻の返事を用意する（話をそらしたとき、
  火種を消したあと、などで変える）。
- 地雷の定型文（「余計なひと言」）: 送ると、火種を全部消していても「火に油」で怒られる。

# 7. 暴言（赤い欄）と魔王化
- 暴言の定型文は全10種（例: 「うるせえ、この鬼嫁」「いちいち細けえんだよ！ほっとけ！」
  「お前は俺の母ちゃんか！説教ならよそでやれ」「黙って寝てろ、この鬼軍曹」
  「いちいち詮索すんな、警察かよ」「家に帰っても全然くつろげないんだよ」
  「最近ご飯、手抜きじゃない？」「昔はもっとかわいかったのにな」
  「お前、お義母さんにそっくりになってきたな」「お前こそスマホばっか見てんじゃねえよ」）。
  毎日このうち4つだけがランダムに出る。
- 1つでも送ると「……既読がついた。返事はない。電話も来ない。」となり、以後は何を送っても
  冷たい返事しか来ない。ドアを開けると、火種に関係なく妻が魔王化している（暗い画面、赤い目、
  画面の揺れ、低いBGM）。最初に送った暴言に合わせた魔王のセリフを用意する
  （例: 「……鬼嫁？」「そう。鬼がお望みなのね。」「いいえ。鬼じゃ足りないわね。」
  「今夜から私は、この家の魔王です。」）。
- 4つ全部送ると「フィナーレ」が発生する（7種からランダム、§9）。

# 8. 酔い（缶ビール）
- コンビニで缶ビールを買い、持ち物から「飲む」と酔いが1段階上がる（最大3段階）。
- 酔うほど画面がフォグと揺れで見づらくなる。ただし揺れは玄関前・街・コンビニ・ゴミ捨て場の
  画面だけ。ドアを開けた瞬間（結末の画面）に「……酔いが、一気にさめた。」と出して演出を止める。
- 酔うと暴言の文面がひどくなる（段階ごとに3パターン。例:
  「うるせえんだよ、この鬼嫁！ 角でも生えてんのか？」→「おにーよめー！！ 鬼ヶ島に帰れ〜〜ｗｗｗ」）。
- 2本以上飲むと、赤い欄に「悪ふざけ」の定型文が出る（3種、赤い欄だけに出す）:
  1. 「交通事故にあって、今病院にいる……」→ 妻は家を飛び出して病院・警察に電話しまくる
     （不在着信×27 などの通知が殺到）→ 帰ると警察官と妻が立っていて「どちらの病院に搬送
     されたんでしたっけ？」→ 捜索願の取り下げ書類を書かされる。
  2. 「駅の階段で足すべらせた……動けない」→ 帰ると玄関に介護ベッド、全身包帯でぐるぐる巻き
     にされる。
  3. 「なんか胸が苦しい……ちょっと道で座って休む」→ リビングで妻が一人で泣いている
     （ここだけ静かでしんみりした結末）。
  悪ふざけを送ったら、火種に関係なく最初に送ったものの結末になる。
- 3本飲んでから暴言を4つ全部送ると、魔王城の魔王が「最終形態」になる（§9）。
- コンビニにカップ清酒（1杯で酔いが一気に3段階目）とスピリタス（96度。飲むと画面がぐるぐる回って
  暗転し、病院のベッドで目を覚まして妻に怒られてゲームオーバー）も置く。
- スマホのSNS「つぶやきー」から投稿できる（1回2分）。酔いの段階ごとに3つずつ文面が出る。
  しらふ: 「今日も一日おつかれ自分」など仕事の愚痴で無害（妻がいいねする）。酔うほど妻の悪口が
  ひどくなり（酔い1: 小言・小遣いの愚痴 → 酔い2: 料理や休日の悪口 → 酔い3: 最低の悪口）、
  投稿は火種になる。妻に見られる前に削除すればセーフ: 酔い1は 0:00 まで、酔い2は10分後、
  酔い3は即バズって手遅れ。

# 9. フィナーレ（暴言4つ全部の日）— 7種からランダム
1. 魔王城: 送った瞬間スマホにひびが入り「妻によってリモート初期化されました」。以後スマホは
   使えない。視界が歪んで玄関前に強制ワープし、ドアが魔王城の門になる。引き返そうとすると
   結界に弾かれる（試すたびに違うメッセージ、最後は「まおうからは にげられない！」）。
   ドアを開けるとドラクエ風コマンドバトル「まおう が あらわれた！」。
   コマンド: たたかう / にげる / どうぐ / どげざ。たたかう・にげる・どうぐは毎回ランダムな
   ギャグ（「よわよわしすぎて ダメージを あたえられない！」「まわりこまれてしまった！」等）で
   失敗し、毎ターン魔王が反撃して「こころのHP」（100）が減る（小言、くつしたを投げつける、
   家計簿を開く、黙って微笑む…）。0 になると「あなたの こころは おれた……」。
```
